---
title: "liteio"
description: "A high-performance, S3-compatible object store written in Go."
---

liteio is a ground-up MinIO alternative: Apache-2.0, every management feature
free, deterministic placement with no metadata database, and a data path built to
saturate NVMe and the NIC.

This guide takes you from a running single-node server to a production distributed
cluster. The [compatibility matrix](/reference/compatibility/) tracks exactly what
works today. The [quick start](/getting-started/quick-start/) gets an S3 endpoint
up in under two minutes using only a Go toolchain.
