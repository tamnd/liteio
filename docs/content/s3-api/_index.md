liteio speaks the AWS S3 REST API. This section covers each operation category
with request shapes, response shapes, and working examples. Use any S3 client:
the AWS CLI, `mc`, `rclone`, `boto3`, or a direct HTTP client.

All examples use the AWS CLI with a `liteio` profile pointing at
`http://localhost:9000`. See the [quick start](/getting-started/quick-start/) to
set that up.
